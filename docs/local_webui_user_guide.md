# GenoLigand 本地 WebUI 使用说明

## 科学目标

GenoLigand 从用户输入的物质、序列或结构出发，计算相互作用特征，并在两类空间中寻找可能靶点：

- 已知蛋白数据库：ChEMBL、BindingDB、UniProt、RCSB、BioLiP2、PLINDER、Binding MOAD。
- 宏基因组潜在序列空间：公共宏基因组、微生物蛋白、未注释开放阅读框和预测结构索引。

## 用户只负责输入

普通用户只需要创建项目并提供研究对象。数据库、索引、工具和运行环境由安装流程准备。资源缺失时页面显示阻塞原因，不生成候选。

## WebUI 流程

1. 输入：填写小分子、多肽、蛋白质配体、复合物或自定义基因组/宏基因组输入。
2. 配置：选择已知蛋白通道、宏基因组潜在序列通道、结构和动力学证据。
3. 检查：检查输入、数据库、运行环境、存储和导出条件。
4. 运行：提交完整计算流程并查看当前阶段、下一步动作和运行事件。
5. 结果：查看候选排序、候选详情、结构/口袋、动力学摘要和证据链。
6. 导出：导出科研报告、候选表、证据链、结构与动力学摘要。

## 准备并启动

```powershell
cd D:\Project\rust\GenoLigand
python scripts\setup\install_complete_scientific.py --start-webui
```

浏览器打开：

```text
http://127.0.0.1:19090/
```

该入口会检查科学仓库、科学资源状态和运行工具，并把运行目录放在用户数据目录中。缺少资源时，界面会显示可执行的安装/修复动作。

## 维护入口

普通用户不需要通过命令行运行主流程。维护人员需要检查、重建或修复科学仓库时，可运行安装入口并按页面提示处理阻塞项。

## 结果边界

报告只表达计算预测，不表达实验验证、药效、临床意义或机制确认。
