# GenoLigand 0.9.76 修复案例与验收表

本表记录 0.9.76 的发布范围。核心链路问题全部纳入，条件性增强项保持原状；与核心链路共用同一修改点的构建身份修复随版本发布完成。

## 核心使用问题

| ID | 问题 | 实施方案 | 验收标准 |
|---|---|---|---|
| A01 | 安装运行时落后于源码 | 发布版本、提交号和 build ID，运行时清单与健康接口共同核验 | 安装二进制、清单、API 与最终提交一致 |
| A02 | 文件序列未进入 MMseqs | 从带偏移和摘要的 spool 读取原序列，查询 ID 绑定序列内容 | FASTA、FASTQ、GenBank 可检索，空序列失败 |
| A03 | Docking/MD 固定前三名 | 依据非仿真分和最大可能仿真增益建立自适应 shortlist | 初排第四名以后可进入仿真并改变最终名次 |
| A04 | 查询 3D 结构未参与评分 | 使用即时 USR、USRCAT 和二维特征联合评分 | 三维匹配影响结构分，常驻数据库不扩容 |
| A05 | Foldseek 覆盖不足仍显示完成 | 当前候选按需获取结构，构建运行期临时 Foldseek 库 | 同轮自动补齐；缺失时返回 incomplete_coverage |
| A06 | 无效 ChEMBL 活性污染排序 | 导入和查询两端校验关系、单位、有效性及有限正值 | 零值、负值、缺单位和非精确关系无法得分 |
| A07 | 各阶段使用不同化学实体 | 结构准备产物成为筛选、Docking、MD 的共同实体来源 | 重原子图、微观状态和摘要全程一致 |
| A08 | PDBQT 到 MD 原子映射错误 | 使用显式 atom map 与原始 RDKit 模板恢复坐标 | 卤素、键级、电荷和立体化学保持一致 |
| A09 | 多链、辅因子和多位点处理不一致 | 受体准备清单绑定链、口袋、配体实例及必要组分 | Docking 与 MD 的受体组分集合一致，歧义位点失败 |
| A10 | 非有限评分和伪 pose 被接受 | Python 与 Rust 双层校验有限值、原子、坐标和化学结构 | NaN、Inf、空文件和普通文本 pose 全部失败 |
| A11 | CUDA 可用时仍默认 CPU | MD 默认 preferred，记录平台选择和回退原因 | CUDA 可用时优先创建 CUDA Context，设备证据落盘 |
| A12 | 科学 worker 无总超时 | 统一 deadline，超时终止完整进程树并清除部分结果 | 挂起 worker 进入稳定 timeout FAIL，无残留进程 |
| A13 | 服务崩溃后 running 永久锁定 | 核验 PID，死亡进程对应运行自动转 failed | 重启后项目可重新运行、取消或删除 |
| A14 | Resume 直接覆盖旧状态 | 只接受 failed/resumable，以新 run 重新执行 | completed/running 返回冲突，旧运行记录保持不变 |
| A15 | WebUI 无取消入口 | 运行页调用取消 API，并显示请求状态 | 活动运行可从页面取消并刷新终态 |
| A16 | 终态后页面仍显示旧状态 | 终态重新加载 run、project 和结果数据 | 页面自动显示 completed、failed 或 cancelled |
| A17 | 关键科学产物未在结果页展示 | 增加 onsite、结构短名单、Docking、MD 和失败摘要视图 | 结果页可直接查看真实产物与失败原因 |

## 集中验收

1. Rust 格式、Clippy、工作区测试一次通过。
2. Python 科学 worker 契约与安装器回归一次通过。
3. WebUI 状态、分页、取消、结果展示与下载契约一次通过。
4. 发布 0.9.76 运行时并核验提交号、build ID、健康接口和真实启动。
5. 删除构建缓存、Python 缓存、测试项目、临时输出和 Foldseek 可选预计算索引；保留真实用户项目与必要科学数据库。
